# БиоЭмоКод (BioEmoCode)

**Тип проекта:** Учебное веб-приложение  
**Дисциплина:** ПМ 02 «Осуществление интеграции программных модулей»  
**Учебное заведение:** Факультет СПО ГУАП  
**Период выполнения:** 11–23 мая 2026 г. (72 часа)

---

## 1. Назначение проекта

«БиоЭмоКод» (Биологический экспериментальный модульный образец) представляет собой веб-приложение для численного моделирования и визуализации нелинейной динамики биологических популяций. Разработано в учебных и научно-исследовательских целях.

---

## 2. Реализованные математические модели

| № | Модель | Тип | Назначение |
|---|--------|-----|-------------|
| 1 | Хищник-жертва (Лотки – Вольтерры) | Система ОДУ | Анализ циклических колебаний численности |
| 2 | Распространение эпидемии (SIR) | Компартментальная | Расчёт порога эпидемии и эффективности вакцинации |
| 3 | Конкуренция видов | Логистическая с поправкой | Анализ конкурентного исключения и сосуществования |
| 4 | Рыболовство (Шефера) | Эксплуатация ресурса | Оптимизация промыслового вылова |

---

## 3. Функциональные возможности

- Численное решение систем обыкновенных дифференциальных уравнений методом Эйлера (с коррекцией отрицательных значений);
- Интерактивное управление параметрами (коэффициенты взаимодействия, начальная численность, временной интервал);
- Визуализация результатов:
  - временные графики;
  - фазовые портреты;
  - векторные поля;
- Экспорт данных в форматах PNG, CSV, JSON;
- Валидация входных данных;
- Автоматизированное модульное тестирование (unittest).

## 5. Быстрый запуск

### 5.1. Требования к окружению

- Python 3.9 или выше;
- Менеджер пакетов pip.

### 5.2. Установка и запуск

# Клонирование репозитория
git clone https://github.com/ваш-репозиторий/BioEmoCode.git
cd BioEmoCode

# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
python app.py
После запуска приложение доступно по адресу: http://localhost:8080

5.3. Запуск тестов
bash
python -m unittest discover tests
